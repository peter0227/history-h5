# 少年考古队 · 历史 H5

统编版（2024）《中国历史》七年级上册 第 1 课《远古时期的人类活动》互动学习页。

## 打开方式

直接双击 `index.html` 即可浏览，无需安装依赖或启动服务。页面同时适配桌面端和移动端。

## 文件结构

- `index.html`：页面结构与全部课文内容
- `styles.css`：漫画风视觉、响应式布局与动效
- `app.js`：地图切换、档案卡翻转、火种实验、小测验、滚动导航
- `assets/hero-scene.svg`：史前黄昏主视觉
- `assets/china-map.svg`：古人类遗址分布示意图
- `assets/beijing-skull.svg`：北京人头骨风格插画
- `assets/shandingdong-figure.svg`：山顶洞人动漫形象

## 内容范围

第 1 课主线：我国境内古人类（元谋人、蓝田人、郧县人）→ 北京人 → 山顶洞人。

页面包含时间轴、遗址地图、三张考点档案卡、北京人用火小实验、北京人与山顶洞人对比表，以及 5 道随堂测验。年代均为教材约数；地图为示意，不作为精确地理测量依据。

## 部署

将整个目录上传到任意静态托管（GitHub Pages、Netlify、Vercel、学校服务器等）即可。页面没有构建步骤，也没有外部 CDN 依赖。
